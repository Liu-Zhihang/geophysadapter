Physics-Informed Landslide Dataset (PILD)

Metadata and protocol assets for GeoPhysAdapter / PILD.

Primary corpus:
- 7,890 samples
- 55 canonical events
- four public sources
- event-isolated evaluation folds

Contents include sample manifests, split definitions, protocol summaries and hashes, source-license notes, and download pointers. Raw imagery is not included; please obtain it from the original providers.
