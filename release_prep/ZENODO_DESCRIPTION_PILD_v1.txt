The Physics-Informed Landslide Dataset (PILD) release v1.0 is a public dataset package prepared for cross-domain landslide mapping research. The release exposes event-level metadata, benchmark split tables, protocol summaries, source registries, and reproducibility-facing documentation for a heterogeneous benchmark assembled from multiple landslide source families. The public release is designed to support manuscript review, auditability, and downstream benchmarking without redistributing all upstream raw imagery or environmental products, which remain governed by the licenses and distribution policies of their original providers.

The release includes the canonical event master table, the strict_t2 event index, split files for in-domain, leave-one-dataset-out, and cross-trigger evaluation, a DLR-centered strict_t3 event summary, a data card, a data dictionary, a source registry, a source license matrix, upstream download pointers, a global benchmark coverage figure, and a release-safe rendering script for the coverage map. The package is intended for benchmark definition, protocol reproduction, and source-traceable experiment reconstruction.
