# License Note for `PILD_release_v1`

## 1. Scope

This public release is a metadata and protocol package for the Physics-Informed Landslide Dataset (`PILD`).

Unless otherwise noted, the following release-authored components may be shared under `CC BY 4.0`:

- release documentation
- event and split metadata authored for the benchmark definition
- protocol summaries
- source registry entries written for the release
- figure assets generated by the project
- lightweight release scripts

This package does **not** claim relicensing rights over third-party raw imagery, labels, or environmental products.

Upstream datasets and environmental layers retain their original licenses and distribution conditions. Their inclusion in project experiments does not imply that they may be redistributed through this release.

For source-specific guidance, see:

- `docs/SOURCE_LICENSE_MATRIX.md`
- `docs/DATA_SOURCE_REGISTRY.md`

## 3. Redistribution Rule

If a file originates from an upstream provider and its redistribution terms are not explicitly cleared for this release, that file should not be included in the public Zenodo package.

Instead, the release should provide:

- a citation
- an official source link
- an acquisition or filtering note

Users of this release should cite:

1. the `PILD` data release DOI once minted
